Each one is built natively for both platforms, runs fully on the phone with no account, no ads and no internet permission, and is released on GitHub with automated builds.

Duedial

Subscription and bill tracker with reminders

Platforms
Android, iPhone and iPad
Stack
Kotlin, Jetpack Compose, Room; Swift, SwiftUI
Release
v1.3.1
  • Plan types for subscriptions, free trials, free tiers and lifetime purchases, with a monthly total that spreads longer plans across months.
  • Reminders are scheduled on the device, so they fire even when the app is closed.
  • Backups move between Android and iPhone: export on one, import on the other.

Target

Habit and goal tracker with streaks and charts

Platforms
Android and iPhone
Stack
Kotlin, Jetpack Compose, Room, Health Connect; Swift, SwiftUI
Release
v1.0.1
  • Targets, not to-dos: done or not, by a time of day, or an amount such as kilometres or steps.
  • On Android, steps, distance and active time from Samsung Health tick targets automatically through Health Connect.
  • Streaks that rest days and skips don't break, hit rates over 7, 30 and 90 days, and a heatmap for each target.

University project

Cohort Hub In development

A web app that gives my study group, PSe-6 at Kauno Kolegija, one place for its week: timetable, deadlines and course updates. It is the project for my Software Systems Engineering course, taken from requirements through to a working, secured application.

Done

  • Requirements specification with 44 functional requirements
  • Data flow diagrams with seven data stores
  • UML activity diagrams and written scenarios for the core processes

Design decisions

  • Imports course-level dates only, never grades
  • Calendar import from files, plus its own calendar feed
  • Roles, audit log and secure sessions designed in from the start

Next: the build

  • Node.js and Express back end
  • PostgreSQL database
  • Hosted web app with continuous deployment from GitHub
